额定排量 = 铭牌最大流量 × 工况折减 0.65 × 出勤占空 0.85。铭牌值是近零扬程下的最大流量， 不能直接用；城市积水抽排的实际 TDH 在 10–20 m，离心泵在该点约为最大流量的 55–75%， 再扣加油、转场、清堵占用的时间。这三个数仍不是贵方的实测值，是我方按公开产品规格推算的暂定值。

影响
第三道防线的全部泵数结论。以 25 年一遇、市区 501 个点为例，模型给出 689 台泵 （12″ 80 / 8″ 135 / 6″ 474）， 对照在册 —— 计算范围内 103 / 83 / 574，市区全口径 144 / 121 / 579。 按旧的统一 300 m³/h 口径则为 763 台，两者同量级。

该结论对排量敏感，且敏感的是构成而非总量：若三档实测排量只有上表的 2/3 （501 / 192 / 147 m³/h），总需求反降到 585 台，但构成翻转为 12″ 312 / 8″ 26 / 6″ 247 —— 12″ 需求从 80 台跳到 312 台，是计算范围内在册 103 台的 3 倍。 换言之，排量取值直接决定该采购哪一档，这正是本项仍需贵方确认的原因。

请提供
12″ / 8″ / 6″ 三档的额定排量（m³/h），并注明是铭牌值还是现场工作扬程下的实测排量 —— 请直接确认或替换上表的 751 / 287 / 221，反驳一个具体数字比填一张空表快。 若车队含电泵与发电机组，一并提供。另请提供驻点位置与当前可用率， 用于出动半径与响应时间测算。
